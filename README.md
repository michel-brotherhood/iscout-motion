# iSCOUT Motion

Repositório de pré-produção, identidade visual, assets e documentação do projeto de motion design da iSCOUT TECH.

## Organização

- `assets/brand/` — logotipos e aplicações oficiais autorizadas.
- `assets/fonts/` — fontes com licença de uso adequada.
- `assets/interfaces/` — capturas reais do produto previamente autorizadas para divulgação.
- `assets/references/` — referências visuais com origem registrada.
- `assets/footage/` — fotos, vídeos e filmagens licenciadas.
- `docs/briefing.md` — objetivos, roteiro e requisitos de produção.
- `docs/brand-guide.md` — identidade visual aprovada.
- `docs/assets.md` — inventário, origem e licenças.

> Não adicionar segredos, dados pessoais, telas com informações reais de clientes, fontes restritas ou materiais sem licença. O repositório é público até que sua visibilidade seja alterada nas configurações do GitHub.
